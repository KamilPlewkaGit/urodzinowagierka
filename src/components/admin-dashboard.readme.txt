File: `src/components/admin-dashboard.tsx`

Purpose and responsibilities: Provides the Polish administrator dashboard for game/player management, SOLENIZANT, and focused The Floor, SPORT, Jaka to melodia?, and Pojedynki control surfaces.

Important exports, inputs, and outputs: `AdminDashboard({ initialSnapshot })` polls the authenticated snapshot, routes navigation/restart actions to the active segment, renders five-segment navigation, and mounts the focused active control surface for The Floor, SPORT, Jaka to melodia?, or Pojedynki.

Dependencies: Casino logo, focused Floor/SPORT/Melodia/Pojedynki controls, Next router, constants/chip/Solenizant helpers, and shared types.

Backend/database interactions: Indirect through the safe state endpoint and protected start, SOLENIZANT, game-navigation/reset, and player-management endpoints. Each endpoint verifies the administrator session and writes through `database.ts`.

Implementation details: The dashboard has five direct-navigation choices and enables previous/next when a neighboring segment exists. Segment restart selects the matching dedicated endpoint. Removal always asks for Polish confirmation, sends `{ playerId }` through the protected endpoint once while all actions are disabled, refreshes the snapshot on success, closes any active chip editor for that player, and displays a Polish status notice. The Floor, SPORT, Melodia, and Pojedynki workflows are isolated in child components; SOLENIZANT selection/scoring and player administration remain unchanged.

Future expansion: Add a separate protected workflow for another segment rather than turning this component into a generic browser-side state editor.

Segment V update: Navigation now has a fourth option, `Jaka to melodia?`, with an independent restart endpoint and status label. `MelodiaAdminControls` is mounted only for an authenticated administrator viewing that active segment; its five-song progression, scoring, and market settlement remain isolated from existing controls.

Segment VI update: Navigation now includes a fifth option, `Pojedynki`, with its own status labels and restart endpoint. `PojedynkiAdminControls` is mounted only while that segment is active, keeping its four team-duel actions separate from all prior segment controls.

The game-start panel tells the administrator where the active segment appears in the player dashboard.
