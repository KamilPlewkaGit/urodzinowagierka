POST wymaga administratora i przyjmuje `{ eventId, winnerTeamId }`. Zatwierdzenie zapisuje zwycięstwo warte 1 punkt oraz standardowe transfery w jednej transakcji. Dodatkowe `correctionRevision` aktualizuje zwycięzcę rozliczonego głównego wyzwania i jego punkt w klasyfikacji. Wypłaty pozostają w saldach.
