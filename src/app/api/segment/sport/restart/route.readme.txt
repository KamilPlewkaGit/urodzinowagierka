File: `src/app/api/segment/sport/restart/route.ts`

Purpose and responsibilities: Provides the explicit administrator-only SPORT restart used by global segment controls.

Important exports, inputs, and outputs: Bodyless admin-only `POST(request)` returns `{ ok: true }` or Polish errors.

Dependencies: Next Route Handler APIs, opaque sessions, and `database.ts`.

Backend/database interactions: Refunds pending SPORT stakes, clears SPORT setup/challenge/bonus state, removes the main-challenge points, and returns SPORT to `intro`. Settled balances and already-awarded bonus points are preserved.
