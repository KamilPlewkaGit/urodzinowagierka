Administrator zatwierdza zwycięzcę zakończonego pojedynku, przesyłając `{ eventId, winnerTeamId }`. Identyfikator z migawki wiąże żądanie z konkretnym pojedynkiem. Wynik, rezerwy i transfery są zapisywane atomowo. Błąd składu, salda lub etapu zwraca polski konflikt.

Zapis rozliczonego zwycięstwa daje drużynie 1 punkt w klasyfikacji ogólnej.
