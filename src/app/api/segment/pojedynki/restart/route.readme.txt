File: `src/app/api/segment/pojedynki/restart/route.ts`

Purpose and responsibilities: Restarts only Segment VI from the shared administrator navigation panel.

Important exports, inputs, and outputs: Bodyless administrator-only `POST(request)` returns `{ ok: true }` or Polish errors.

Dependencies: Next Route Handler APIs, opaque sessions, and `restartPojedynkiSegment`.

Backend/database interactions: Refunds pending Pojedynki wagers, deletes Segment VI bets, results and their points, and returns its state to `intro`. It preserves accounts, teams, other segments and already-settled balances.

Implementation details: Bets are deleted before their foreign-key duel rows; settled payouts are deliberately not reversed by a segment restart.
