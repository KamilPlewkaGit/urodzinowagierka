File: `src/app/api/segment/melodia/scoring/route.ts`

Purpose and responsibilities: Opens administrator scoring for the currently displayed music song while keeping player screens on that song.

Important exports, inputs, and outputs: Admin-only bodyless `POST(request)` returns `{ ok: true }` or Polish errors.

Dependencies: Next Route Handler APIs, opaque sessions, and `openMelodiaScoring`.

Backend/database interactions: Transitions only the current durable song from `live` to `scoring` and the segment stage from `song` to `scoring`.

Implementation details: No points, winner, bets, or music metadata are accepted here.
