File: `src/app/api/segment/melodia/start-song/route.ts`

Purpose and responsibilities: Lets the administrator close the pre-song market and expose Song 1.

Important exports, inputs, and outputs: Admin-only bodyless `POST(request)` returns `{ ok: true }` or a Polish authorization, conflict, or server error.

Dependencies: Next Route Handler APIs, opaque sessions, and `startFirstMelodiaSong`.

Backend/database interactions: Atomically changes the first persisted song from pending to live and the game stage from betting to song. It does not play music or change scores.

Implementation details: Later songs are opened only by the separate next route after confirmed scoring.
