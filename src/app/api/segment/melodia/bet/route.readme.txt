File: `src/app/api/segment/melodia/bet/route.ts`

Purpose and responsibilities: Accepts one player bet on the team that will lead Segment V after all five songs.

Important exports, inputs, and outputs: Player-only `POST(request)` validates `{ targetTeamId, stake }` with `melodiaBetSchema` and returns `{ ok: true }` or Polish errors.

Dependencies: Next Route Handler APIs, opaque sessions, `melodiaBetSchema`, and `placeMelodiaBet`.

Backend/database interactions: The service derives the bettor from the verified session, permits the persisted `betting` phase only, checks active status/balance/one-bet uniqueness, atomically debits the server decimal stake, and inserts the bet.

Implementation details: The browser never submits a player ID or balance. Betting closes when the administrator starts Song 1.
