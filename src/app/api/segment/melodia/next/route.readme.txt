File: `src/app/api/segment/melodia/next/route.ts`

Purpose and responsibilities: Opens exactly the next pending song after a confirmed earlier result.

Important exports, inputs, and outputs: Admin-only bodyless `POST(request)` returns `{ ok: true }` or a Polish conflict/authorization/server error.

Dependencies: Next Route Handler APIs, opaque sessions, and `moveToNextMelodiaSong`.

Backend/database interactions: The service locks the current result, marks only the following fixed slot live, and increments the persisted song sequence.

Implementation details: It cannot skip a song or open a sixth song; Song 5 moves directly to durable final settlement.
