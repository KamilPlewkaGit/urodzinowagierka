File: `src/app/api/admin/login/route.ts`

Purpose and responsibilities: Checks the fixed administrator password and issues an administrator session cookie.

Important exports, inputs, and outputs: `POST(request)` accepts `{ password }`, returns `{ ok: true }` on success, or a safe Polish `{ error }` response on malformed/invalid credentials.

Dependencies: `src/lib/validation.ts` and `src/lib/session.ts`.

Backend/database interactions: Creates an opaque administrator session row through `src/lib/session.ts` and `src/lib/database.ts`.

Implementation details: The password is the literal `admin`; only an exact server-side match creates a session. This intentionally convenient password is suitable only for a trusted private game, because anyone who knows it can administer the game. The password and opaque session token never enter client bundles or JSON responses.

Future expansion: Restore an environment-configured, bcrypt-hashed password before exposing the game to untrusted users. Keep server-side session issuance in this boundary.
