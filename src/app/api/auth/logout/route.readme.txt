File: `src/app/api/auth/logout/route.ts`

Purpose and responsibilities: Revokes either player or administrator browser session and clears its browser cookie without needing to inspect the role.

Important exports, inputs, and outputs: `POST(request)` returns `{ ok: true }`, revokes the supplied session token, and expires the `casino_session` cookie immediately.

Dependencies: `src/lib/database.ts` and `src/lib/session.ts` for session revocation and shared cookie options.

Backend/database interactions: Deletes the opaque session row matching the request cookie through `revokeSession`.

Implementation details: It preserves cookie attributes such as path and SameSite when expiring the cookie so browsers replace the original cookie correctly. A missing or expired token is harmless and still results in a successful logout.

Future expansion: Add a server-side sign-out-of-all-devices flow only if the game needs it.
