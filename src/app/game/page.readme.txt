File: `src/app/game/page.tsx`

Purpose and responsibilities: Protects and renders the basic active-game screen after the administrator starts the game.

Important exports, inputs, and outputs: `GamePage` loads the snapshot and returns `GameScreen`; it redirects signed-in users back to the appropriate waiting surface while status is `waiting`.

Dependencies: `src/lib/session.ts`, `src/lib/database.ts`, and `src/components/game-screen.tsx`.

Backend/database interactions: Reads the session and current Neon game state/players.

Implementation details: Both authenticated players and the administrator may view the live screen. The role is passed only to decide whether to display the command-table link.

Future expansion: Future game mode routing should still verify game membership/role on the server before rendering a round.
