File: src/lib/familiada.ts

Purpose: Defines the eight ordered Polish question sets and server-side rules for Segment VIII. It is marked server-only and has no database access.

Inputs and outputs: advanceFamiliada accepts the stored document, a validated gameplay command, resolved active representatives and, for buzzes, a session-derived player ID. It produces the next document or a Polish FamiliadaConflict. getFamiliadaSnapshot explicitly projects that document and aggregate/private bet rows into the shared read model.

Dependencies: Shared Familiada types, the inferred server validation contract and server-only.

Implementation: Saving matchups seeds the exact question text and descending answer values. The state machine governs opening priority, ranked answer reveals, strikes, stealing, presentation reveals, and stage changes. Match scores sum awarded round pools. Hidden slots have a position and null reveal. The full key for the current question is emitted only for the admin projection. Revision and transaction checks belong to database.ts.

After the opening face-off, mistakes count toward the answering team's three-strike limit for the question. The controlling team's third strike starts the steal, and the opponent either wins with a hidden answer or concedes the pool on its own third strike. The legacy scalar belongs to the controlling team. A recorded legacy failed steal counts as one opponent strike and retains the saved round result.
