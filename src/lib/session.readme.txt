File: `src/lib/session.ts`

Purpose and responsibilities: Creates database-backed, short-lived application session cookies and exposes helpers for server pages and Route Handlers.

Important exports, inputs, and outputs: Exports cookie constants/options, player/admin session creators, `getCurrentSession`, and `getRequestSession`. It accepts a player ID or request and returns a verified `Session` or `null`.

Dependencies: Next `cookies`, NextRequest types, `src/lib/database.ts`, and `src/lib/types.ts`; `server-only` prevents client imports.

Backend/database interactions: Creates and resolves opaque session tokens exclusively through `src/lib/database.ts`.

Implementation details: The browser holds an opaque random token in an HttpOnly, SameSite=Lax, production-secure cookie. The server resolves its role, player ID, and expiry from Neon, so there is no client-authoritative role claim and no `SESSION_SECRET` environment variable.

Future expansion: Add issuance metadata or a sign-out-of-all-devices flow only if the game needs it; keep authorization server-verified.
